# Testing

- This project uses **Vitest** as the test runner, NOT Jest.
- Run tests with: `npx vitest run` (single run) or `npx vitest run --reporter=verbose` for detailed output.
- Run specific test files with: `npx vitest run path/to/file.test.ts`
- Test files use the `.test.ts` extension and are co-located with source files.
- Do NOT use `jest`, `npx jest`, or any Jest CLI commands.
